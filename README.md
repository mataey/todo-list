# React Todo List Application

A professional, portfolio-ready Todo application built with React and Vite, featuring robust state management, secure user authentication workflows, client-side validation, and responsive modern styling.

## live Demo
[View Live Application](https://your-app.vercel.app) *(Update this link after deploying to Vercel)*

## Features
- **CRUD Operations:** Create, read, update, and delete todo items seamlessly.
- **Filtering System:** Filter todos by status (All, Active, Completed).
- **Secure Authentication:** Protected routes and login flow.
- **Input Validation:** Client-side form validation to prevent empty submissions and ensure data integrity.
- **Responsive Design:** Optimized layout for mobile, tablet, and desktop viewports.

## Technologies Used
- **React (Vite)** - Fast frontend framework and build tool.
- **JavaScript (ES6+)** - Core programming language.
- **CSS Modules / Modern CSS** - Scoped component styling.
- **Vercel** - Production static site hosting and serverless proxy configurations.
